## Featured Projects

| Project | Description |
|---|---|
| **MinuteMate** | Chrome Extension that captures meeting audio, transcribes it with **OpenAI Whisper** via a **FastAPI** backend, and turns it into structured notes and action items with **Google Gemini** — auto-delivered to GitHub Issues, Notion, and Slack. |
| **Statistical Analysis of U.S. Border Immigration** | Dual-border, state-level ML study across 402,318 Bureau of Transportation Statistics observations and 14 states. Benchmarked **CatBoost, LightGBM, XGBoost, and OLS** with lag/rolling features; best result **R² = 0.848** (feature-augmented CatBoost). Co-authored, published in Springer ISEM. |
| **EquiEval** | Ordinal employee-performance-classification pipeline (**Random Forest, XGBoost, CatBoost**) with VIF/RFE feature selection and **ADASYN** for class imbalance; compared six GridSearchCV-tuned scenarios using bootstrap resampling and pairwise significance testing rather than raw accuracy alone. |
| **ToT Trecks** | Real-time baby-cry audio classifier using **Keras/TensorFlow**, **PyAudio**, and **Librosa**, with a **Flask** dashboard and **SQLite** event logging for timestamped historical analysis. |
